# Dateien

Die vollständige Dateiliste mit SHA-256-Prüfsummen steht in `MANIFEST.sha256` im Paketstamm. Das Paket folgt der Website-Ordnerstruktur. Die Installationsanleitung im Paketstamm beschreibt Backtester, englische Oberfläche, gemeinsame Dateien und Währungsdienst.

Produktive Konfigurationen und Laufzeitprotokolle sind ausgenommen. Die Konfigurationsvorlagen enthalten keine privaten Zugangsdaten. CSV-Importdateien und die vorhandene Datenbeschaffung sind enthalten.
