# Assetklassen-Backtester

Version 1.3, Stand 28.10.2026. Vergleich von 13 Anlageklassen, Portfolioeditor, regelgebundene Gewichtssuche, Steuermodell und lokale Speicherung.

Die vollständige Installationsanleitung steht in der [README im Paketstamm](../../README.md). Funktionsweise und Berechnung sind in [docs/PORTFOLIOS-V1.3.md](docs/PORTFOLIOS-V1.3.md) beschrieben. Änderungen dieser Version stehen in [docs/RELEASE-v1.3.md](docs/RELEASE-v1.3.md).

Benötigt werden PHP 8.1+, MySQL/MariaDB und die eigene private Konfiguration. Die Vorlage liegt unter `config/backtester.example.php`; die Importdateien liegen unter `var/import/`.
