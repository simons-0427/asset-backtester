# Assetklassen-Backtester

Interaktives Dashboard zum Vergleich von verschiedenen Assets über 10 Jahre. Vergleichsszenarien für die Frage: „Was wären aus 10.000 € geworden?“

[Projektseite](https://smstark-projekt.de/projekte/backtester.html) | [Downloads](https://smstark-projekt.de/downloads.html)
